# Preset: workout-routine
A routine: one clip per exercise.

- **Typical length:** 30–60s
- **Pacing:** clean cut per exercise, 3–6s each (enough reps to show form), cuts land on the beat.
- **Captions:** only if there's a voiceover / talking.
- **Text overlays:** lower-third label on every exercise: name + sets × reps ("Bulgarian split squat" / "3 × 10").
- **Music:** energetic, music leads; gym sound muted.
- **Transitions:** hard cuts.
- **Colour grade:** punchy.
- **End card:** on.

## Structure
1. Hook: the hardest / best-looking rep + title ("Leg day that actually works").
2. One segment per exercise, label on screen the whole time.
3. Optional recap or "save this" line at the end.
